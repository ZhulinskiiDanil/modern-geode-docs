## Сначала сигнатура, затем контекст

Ниже — небольшой проверенный набор символов из заголовков v5.10.1. Это не полный автоматически сгенерированный API. Каждый символ связан с исходником конкретной версии.

## Поиск символа

Ищите по имени и namespace, фильтруйте по типу. Используйте Tab и Enter. URL fragment сохраняет выбранный символ для прямой ссылки.

## Безопасное использование

Изучите типы параметров, возвращаемое значение и пример. Borrowed view не является собственной строкой. Указатель загрузчика нельзя удалять вручную. Доступность означает наличие объявления в этом SDK; каждая платформа требует сборки и проверки.

## Дальше

Для остальных overloads и классов используйте полный официальный API. Типизированный ApiAdapter позволяет заменить источник данных без изменения browser.

[Официальный API](https://docs.geode-sdk.org/classes/geode/Mod/)
