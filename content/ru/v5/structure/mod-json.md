## Назначение

Загрузчик читает этот файл, чтобы определить мод и проверить совместимость перед загрузкой бинарника. Файл лежит в корне, рядом с CMakeLists.txt.

## Место в проекте

Пример заявляет только Windows. Добавляйте платформу после сборки и проверки с нужной версией игры. Замените ID и автора собственными значениями.

## Пример

```json [mod.json]
{
  "geode": "5.10.1",
  "gd": {
    "win": "2.2081"
  },
  "id": "yourname.hello-geode",
  "name": "Hello Geode",
  "version": "1.0.0",
  "developer": "Your name",
  "description": "A small learning mod.",
  "dependencies": {
    "geode.node-ids": ">=v1.23.3"
  }
}
```

## На что обратить внимание

geode — целевой SDK, gd — совместимость с игрой, version — версия вашего мода. Не путайте эти три значения. Зависимость node-ids нужна для кнопки из tutorial.

## Проверка результата

JSON не поддерживает комментарии и завершающие запятые. Сохраняйте ID между обновлениями: по нему определяются зависимости и данные. После сборки проверяйте сообщения загрузчика о совместимости.
