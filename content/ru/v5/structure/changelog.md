## Назначение

Этот необязательный Markdown-файл в корне хранит историю релизов. Он помогает игрокам понять изменения перед обновлением.

## Место в проекте

Начните с изменений, заметных пользователю. Укажите исправления, совместимость и необходимые действия. Новую версию размещайте сверху и согласуйте её номер с mod.json.

## Пример

```markdown [changelog.md]
# Changelog

## v1.0.1

- Fix the menu button layout.

## v1.0.0

- Add the menu button.
```

## На что обратить внимание

Изменение changelog само по себе не меняет версию пакета. Повышайте version в mod.json и публикуйте новый пакет. Не подменяйте файл уже выпущенного релиза.

## Проверка результата

Проверьте упакованный changelog в Geode, совпадение версии и работу ссылок. Инструкции поддержки, не относящиеся к изменениям, храните отдельно.
