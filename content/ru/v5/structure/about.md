## Назначение

Этот Markdown-файл описывает мод игрокам внутри Geode и лежит в корне проекта. README репозитория помогает разработчикам, а about.md объясняет установленный мод игрокам.

## Место в проекте

Опишите видимую функцию, способ её найти и ограничения. Короткое description из mod.json служит резюме, а не заменой этой страницы.

## Пример

```markdown [about.md]
# Hello Geode

Adds a small button to the main menu.

## How to use

Open the main menu and click the new button.
```

## На что обратить внимание

Замените текст шаблона перед распространением. Инструкции должны быть понятны без чтения исходников. Укажите зависимости и конфликты, которые влияют на игрока.

## Проверка результата

Соберите и установите пакет, откройте страницу информации о моде и проверьте Markdown. Не предполагайте поддержку всех возможностей GitHub Markdown: проверьте заголовки и ссылки прямо в Geode.
