## Классы и наследование

Класс объединяет состояние и поведение. MenuLayer — класс игры. Geode добавляет поведение через механизм hooks; это не обычная замена всех экземпляров игры наследником C++.

## Указатели и ссылки

Указатель хранит адрес и может быть null. Ссылка обозначает существующий объект. Поиск node может ничего не найти: проверьте результат перед вызовом через `->`. В C++ нет автоматического пропуска обращения, как у optional chaining JavaScript.

## auto и const

`auto` выводит тип на этапе компиляции, а не делает его динамическим. `const` ограничивает изменение через переменную. `auto const&` позволяет читать значение без копирования.

## Владение и время жизни

cocos2d использует подсчёт ссылок и autorelease. Родитель удерживает дочерние nodes; удаление из родителя может освободить объект. Не помещайте autoreleased node в std::unique_ptr и не вызывайте delete. Модель владения указателя должна соответствовать объекту.

## Полный первый пример

Поместите в src/main.cpp созданного проекта:

```cpp
#include <Geode/Geode.hpp>
#include <Geode/modify/MenuLayer.hpp>
using namespace geode::prelude;

class $modify(MenuLayer) {
    bool init() {
        if (!MenuLayer::init()) return false;
        log::info("The menu is ready");
        return true;
    }
};
```

bool сообщает результат инициализации. Ранний return не позволяет продолжить работу после ошибки оригинала.

## Частые ошибки

Захват `this` в lambda не продлевает жизнь объекта. Cast не доказывает, что node нужного типа. Templates работают во время компиляции. Разберитесь с владением до сохранения указателя для будущего использования.
