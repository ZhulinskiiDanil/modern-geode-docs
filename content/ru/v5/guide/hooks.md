## Что меняет hook

Hook перехватывает вызов функции. Это не цикл: он не выполняется каждый кадр, если этого не делает сама функция. MenuLayer::init удобен для добавления элементов после создания меню.

## Минимальный полный мод

Нужны созданный проект и работающий компилятор. Замените src/main.cpp:

```cpp [src/main.cpp]
#include <Geode/Geode.hpp>
#include <Geode/modify/MenuLayer.hpp>
using namespace geode::prelude;

class $modify(MenuLayer) {
    bool init() {
        if (!MenuLayer::init()) return false;
        log::info("The menu is ready");
        return true;
    }
};
```

## Порядок выполнения

1. Modify header подключает механизм изменения класса.
2. Сигнатура точно соответствует оригиналу.
3. MenuLayer::init проходит через цепочку hooks и создаёт UI.
4. При успехе записываем сообщение в лог.
5. true сообщает о готовности меню.

## Проверка

Выполните `geode build`, установите пакет, перезапустите игру и откройте главное меню. Найдите “The menu is ready” в логе. Новый экземпляр меню может создать ещё одно сообщение.

## Совместимость и ошибки

Обычно оригинальную функцию необходимо вызывать. Другие моды тоже могут перехватить эту функцию. Не меняйте priority наугад ради порядка вызовов. Для данных изменённого объекта нужен механизм fields Geode; обычное добавление членов класса его не заменяет.
