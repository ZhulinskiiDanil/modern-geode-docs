## Думайте в терминах nodes

UI Geometry Dash — дерево сцены cocos2d. Layer содержит nodes, menu — интерактивные элементы. Sprite сам по себе не кнопка. Официальный пример использует CCMenuItemSpriteExtra как кликабельную оболочку.

## Найдите родителя

Используйте стабильные ID и указывайте зависимость node-ids. Поиск может вернуть null. Правильный родитель важен: позиция, масштаб и видимость зависят от дерева.

## Расположение без случайных чисел

Позиция задаётся относительно родителя. Anchor определяет точку привязки, scale — масштаб отображения. При расширении существующего меню используйте его layout и вызывайте updateLayout после изменения children.

## Практика

Пройдите tutorial первого мода, затем измените текст callback. Полный src/main.cpp демонстрирует sprite, menu item, уникальный ID и обновление layout. Такой небольшой пример проще отлаживать.

## Проверка интерфейса

Откройте и закройте меню, измените размер окна, включите другой мод с дополнительными кнопками. Убедитесь, что кнопка видна, нажимается и не перекрывает элементы. Перед заявлением поддержки телефона проверьте на устройстве.

## Частые ошибки

Жёсткие координаты вызывают наложение на UI других модов. Указатель после освобождения node родителем может стать недействительным. Увеличение sprite само по себе не гарантирует удобную обработку касаний.
