## Read the signature, then the context

The browser below contains a deliberately small, verified selection from the v5.10.1 headers. It is not an automatically generated complete API. Every symbol links to its pinned source.

## Find a symbol

Search by name or namespace and filter by kind. Select a result with the keyboard using Tab and Enter. The URL fragment identifies the selected symbol so you can link to it directly.

## UI classes in this browser

The curated list now includes `geode::Button`, `Popup`, `ScrollLayer`, `Label`, `Notification`, `Layout`, and `TextInput`, alongside the loader's `geode::Mod` class. Each entry includes its pinned header, platform availability, parameters, return type, and a compact C++ example.

## Use a symbol safely

Read the parameter and return types, then inspect the example. A borrowed view is not an owned string. A loader-owned pointer should not be deleted by your mod. Availability here means the declaration is present for this SDK snapshot; you still need a build and runtime check for each platform.

## Go further

For overloads and classes outside this curated set, follow the full official API. Data ingestion can be replaced through the typed ApiAdapter without changing this browser.
