## Purpose

This Markdown file describes your mod to players inside Geode. Keep it in the project root. A repository README explains the project to developers; about.md explains the installed mod to players.

## How this file fits in

Describe the visible feature, where to find it and any limitations. The short description in mod.json is a summary, not a replacement for this page.

## Example

```markdown [about.md]
# Hello Geode

Adds a small button to the main menu.

## How to use

Open the main menu and click the new button.
```

## Things to keep in mind

Replace the template text before sharing the mod. Keep usage instructions understandable without reading the source code. Be explicit about dependencies or conflicts that affect players.

## Verify the result

Build and install the package, open the mod’s information page and inspect the rendered Markdown. Check headings and links in Geode instead of assuming every GitHub Markdown feature is available.
