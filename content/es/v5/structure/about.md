## Propósito

Este Markdown describe el mod a los jugadores dentro de Geode. Va en la raíz. README explica el proyecto a desarrolladores; about.md explica el mod instalado a jugadores.

## Cómo encaja en el proyecto

Describe la función visible, dónde encontrarla y sus limitaciones. description en mod.json es un resumen, no un sustituto de esta página.

## Ejemplo

```markdown [about.md]
# Hello Geode

Adds a small button to the main menu.

## How to use

Open the main menu and click the new button.
```

## Qué debes tener en cuenta

Sustituye el texto de la plantilla. Las instrucciones deben entenderse sin leer código. Indica dependencias y conflictos relevantes.

## Verifica el resultado

Compila, instala y revisa la página de información del mod. Comprueba encabezados y enlaces en Geode; no supongas compatibilidad con todas las extensiones Markdown de GitHub.
